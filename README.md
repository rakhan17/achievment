# GitHub Achievement Hunter

A small public repository for learning GitHub collaboration workflows through real, useful changes.

## Missions

- [x] Initialize the repository and document its purpose.
- [ ] Practice a focused issue-to-pull-request workflow.
- [ ] Practice merging a pull request without requesting a review (YOLO experiment).
- [ ] Collaborate with another developer using a genuine co-authored commit.
- [ ] Host useful GitHub Discussions and earn accepted answers from other participants.
- [ ] Grow the project through useful contributions and organic discovery.

## Ground rules

This repository is an activity playground, not an achievement generator. GitHub awards achievements according to its own eligibility rules and may change those rules. No fake accounts, purchased stars, fabricated co-authorship, self-awarded answers, or spam.

Some achievements require other people to participate. Those steps will remain open until genuine collaboration or community participation happens.
