# Contributing

Thanks for helping improve this repository.

## Good first contributions

- Fix unclear wording or broken links.
- Add a concise example of a GitHub workflow.
- Improve issue and pull request templates.
- Document a real limitation or lesson learned.

## Workflow

1. Open or find an issue describing the change.
2. Create a focused branch.
3. Make a small, meaningful change.
4. Open a pull request with context and testing notes.
5. Merge when the change is ready and repository rules permit it.

## Collaboration

For co-authored work, every named co-author must have genuinely contributed. Use Git's Co-authored-by trailer only with the contributor's agreement and correct GitHub-associated email.

Please do not submit empty, misleading, or achievement-only changes.
